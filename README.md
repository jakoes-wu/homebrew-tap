# jakoes-wu/homebrew-tap

Homebrew formulae for [multi-codex](https://github.com/jakoes-wu/multi-codex), [multi-claude](https://github.com/jakoes-wu/multi-claude) and [ownexit](https://github.com/jakoes-wu/ownexit).

```sh
brew install jakoes-wu/tap/multi-codex
brew install jakoes-wu/tap/multi-claude
brew install jakoes-wu/tap/ownexit
```
